# Papers

Finished SyberLabs studies. Each study is one folder: the writeup and the code that produced it. Both are public.

If a dataset cannot be redistributed, the paper says how to fetch it. The code still lives here. Do not split a study into a public PDF and a private repo — that is two surfaces and a claim nobody can check.

Live products do not belong here. They stay in their own repos: [OmniOS](https://github.com/SyberLabs/OmniOS), [omni-agent](https://github.com/SyberLabs/omni-agent), [RISE](https://github.com/SyberLabs/RISE), [OSAHR_Cell](https://github.com/SyberLabs/OSAHR_Cell), [skypredict-v2](https://github.com/SyberLabs/skypredict-v2).
