# Censoring-Aware Transition-Zone Fit (Log-Normal AFT)

Generated by `src/grokking_scaling_theory/survival_fit.py`. Reproduce with:

```bash
python -m grokking_scaling_theory.survival_fit
```

## Why

`fit_competition` drops censored runs. A censored run is the one-sided
observation `tau > T_budget`, not missing data. The only censored run
(p=31, `tau > 20000`) sits at the small-p edge of the transition zone
exactly where the inverted-scaling claim is decided, so excluding it
biases the zone's exponent toward zero.

## Model

Tobit regression in log space: `log tau = x . theta + sigma * eps`,
observed runs contribute the normal density, censored runs the survival
probability `1 - Phi((log T - x.theta)/sigma)`.

Design: `power_only`, i.e. `tau = C * p^a / wd^beta`, on all fit-eligible
runs with `p <= 80` (n=9 events: local sweep p=37..53, validation
p=61/67/71, published p=59). All runs share wd=1.0, so the beta covariate
is automatically pruned as zero-variance (reported as 0.0).

## Result

| Treatment | a (p exponent) | se | sigma | logL |
|---|---:|---:|---:|---:|
| Excluding censored (status quo) | -1.766 | 0.218 | 0.141 | 4.83 |
| Including censored (AFT) | **-2.040** | 0.201 | 0.164 | 3.92 |

## Interpretation

1. **The transition zone is not `tau ~ 1/p`.** The documented `tau ~ k/p`
   label in `HOUND_DOG_FINDINGS.md` and `COLLAPSE_ANALYSIS_RESULTS.md`
   understates the inversion. Even excluding the censored point, the free
   exponent is -1.77; with the censored point correctly used, it is
   **-2.04 +/- 0.20**.

2. **`tau ~ p^{-2}`: the inverted mirror of the forward law.** The
   censoring-corrected zone exponent is consistent with exactly -2, the
   mirror image of the `p^2` burden in the Fourier regime. This is either
   a coincidence of a small dataset or a structural clue: if escape from
   the memorization basin is rate-limited by a quantity proportional to
   the training-set size (`N ~ p^2` at fixed train fraction), an escape
   rate linear in N gives `tau ~ 1/p^2` directly. That reading connects
   the transition zone to circuit-efficiency accounts in which growing
   dataset size makes the memorizing solution progressively costlier.
   It also sharpens the train-fraction experiment: at fixed p, varying
   train fraction changes N without changing p, and the two readings
   (`p^{-2}` as modulus scaling vs. `N^{-1}` as data scaling) decouple.

3. **The censored point was load-bearing.** The exponent shift (-1.77 ->
   -2.04) exceeds one standard error and comes entirely from information
   that the previous workflow discarded. The p=31 run's failure to grok
   within budget is evidence, and using it moves a headline number.

## Caveats

- Single seed per point; sigma here absorbs both protocol noise and seed
  variance without distinguishing them.
- The published p=59 anchor is included as an event; its protocol differs
  from the local sweep. Rerunning with `modulus_range=(32, 80)` restricted
  to local sources is a one-line change and should be reported alongside.
- Published anchor rows encode `max_epochs == grokking_epoch` (budget
  unknown), so censoring detection uses explicit notes markers only. New
  runs should record the true budget so detection can be structural.

## Follow-ups

- Add `train_fraction` and `batch_size` to the run-table schema so the
  `p^{-2}` vs. `N^{-1}` degeneracy is breakable.
- Multi-seed replication at p in {31, 37, 43}: the spinodal reading of the
  zone predicts seed-variance of tau peaks near the basin boundary.
- Extend the AFT comparison to the Fourier regime once a measured-only
  ladder with recorded budgets exists at p > 113.
