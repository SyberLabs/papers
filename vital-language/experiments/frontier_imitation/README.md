# Frontier Imitation Probe

This experiment asks whether a frontier model can reproduce literary vitality by prompt alone.

The public folder includes:

- `RESULTS.md`: summarized findings and caveats.
- `PROMPTS.md`: prompt templates used for matched imitation/control generation.
- `ALLUSION_PROBE.md`: protocol and interpretation for the allusion-depth probe.
- `analyze.py` / `analyze2.py`: analysis scripts for trajectory and channel metrics.

Excluded from the public package:

- hidden probe keys,
- raw blind excerpts,
- private judge files,
- copyrighted source windows.

The result should be read as directional. It is useful because it separates style register from structural discipline, not because it proves a general law of literary generation.
